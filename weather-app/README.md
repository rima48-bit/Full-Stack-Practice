# Weather App

A simple weather application built with React that fetches real-time weather data using the OpenWeather API.

## Features

- Search weather by city
- Temperature, humidity, and wind speed
- Dynamic weather icons
- Loading and error handling
- API key stored using environment variables

## Tech Stack

- React
- JavaScript
- CSS
- OpenWeather API
- Vite

## What I Learned

- Working with APIs
- Fetch and JSON
- Async/Await
- React `useState` and `useEffect`
- Error and loading states
- Environment variables
